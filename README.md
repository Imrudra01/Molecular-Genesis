# Molecular-Genesis
What happens when atoms are set free? ⚛️ Explore elements from Hydrogen to Calcium, watch them collide, bond, and assemble into molecules. The simulation brings chemistry to life with dynamic interactions and VSEPR-driven molecular geometry, turning invisible rules of matter into an interactive 3D playground.
